# السابقون (As-Sabiqun) — Android app

Friendly circles that encourage each other to pray at the mosque.

**Download the latest version:**
https://github.com/youssef8890/as-sabiqun-releases/releases/latest/download/as-sabiqun.apk

Install: open the link on your Android phone, open the downloaded file, allow "Install unknown apps" for your browser if Android asks, then tap Install.

This repository holds only the installable app files. The source code is private.
